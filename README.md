# SmartERP Agentic Framework

> How AI agents are transforming ERP Systems: From Claude MCP to Open code and Autonomous agents

An AI-powered Enterprise Resource Planning (ERP) solution built to bridge natural language queries with enterprise databases and automate supply chain procurement.

**Live Demo:** [https://erpframe.streamlit.app/](https://erpframe.streamlit.app/)

---

## Key Features

### 1. Control Center & Executive Analytics
* **Real-Time KPI Tracking:** Instant metric summary for total products, stock valuation, total revenue, and low-stock alerts.
* **Interactive Data Visualizations:** Dynamic Plotly bar and pie charts comparing inventory levels against safety thresholds.
* **Live Data Management:** Complete database management tools to view full tables, add new entries, or delete products.

### 2. Enterprise AI Assistant (Text-to-SQL)
* **Natural Language Interface:** Asks database questions in simple English and gets immediate answers powered by Llama 3.3.
* **Transparent SQL Execution:** Collapsible inspection panel showing the actual SQL query generated by the AI agent.
* **Single-Screen Results:** Dynamic response layout displaying summary text, raw SQL, and result tables without unnecessary scrolling.

### 3. Autonomous Procurement Engine
* **Automated Stock Audits:** Self-monitoring background engine that checks stock levels against safety limits.
* **Automated Purchase Requisitions:** Automatically identifies appropriate suppliers and drafts purchase orders for low-stock items.
* **Human-in-the-Loop Approvals:** Interactive status controls allowing managers to approve or reject requisitions before action.

---

## Technical Stack

* **Frontend & UI:** Streamlit, Custom HTML/CSS
* **Database:** SQLite3
* **Data Processing & Charts:** Pandas, Plotly
* **LLM Engine:** Llama 3.3 (via Groq SDK)
* **Environment Management:** python-dotenv

## Local Setup & Installation

Execute setup steps in your terminal:

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Create .env file and add your API key
echo "GROQ_API_KEY=your_groq_api_key_here" > .env

# 3. Run the Streamlit application
streamlit run app.py
